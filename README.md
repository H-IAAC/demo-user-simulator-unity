# Unity Interface for User Simulation Demo

This repository contains a Unity project that implements an interface for a user simulation demo developed by the Hub for Artificial Intelligence and Cognitive Architectures (H.IAAC) at the State University of Campinas (UNICAMP). The demo is intended for research and prototyping of user simulation components and integrations with cognitive architectures.

See more projects from the group [here](https://h-iaac.github.io/HIAAC-Index).

## Repository Structure

This section lists the main files and folders at the repository root and a short description of their purpose.

- `Assets/`: The Unity project assets (scenes, scripts, prefabs, resources and third-party plugins).
- `Packages/`: Unity package manifest and resolved packages used by the project (`manifest.json`).
- `ProjectSettings/`: Unity project settings required to open the project with the same configuration.
- `Library/`: Unity local cache (ignored by version control in most cases). Not required to commit.
- `config_example.json`: Example configuration file used by the demo to set simulation parameters.
- `README.md`: This file — documentation and usage instructions.
- `*.csproj`, `*.slnx`: C# project and solution files generated by Unity for IDE integration.

Additional notable folders under `Assets/`:

- `Assets/Scenes/`: Example scenes and demo scenes that can be opened to run the simulation.
- `Assets/Scripts/`: C# scripts implementing the demo logic and interfaces to the simulator.
- `Assets/Plugins/`: Native or managed plugins used by the project (if any).

## Dependencies / Requirements


- Unity Editor: Unity 2021.3 LTS or newer.

- [Ultralight SDK 1.2.1](https://docs.ultralig.ht/) or newer. Required for showing HTML pages.

- [UwU bridge](https://github.com/mnottale/uwu). Bridge between Unity and Ultralight SDK.

## Installation / Usage

Quick steps to run the demo locally:

1. Clone the repository:
```bash
   git clone https://github.com/H-IAAC/demo-user-simulator-unity.git
   cd demo-user-simulator-unity
```
2. Open the project in Unity:

   - Open Unity Hub, click "Add", select the repository folder and open it.
   - Allow Unity to import assets and resolve packages.

3. Follow the instructions form [UwU repository](https://github.com/mnottale/uwu) to configure Ultralight SDK and Unity bridge.
